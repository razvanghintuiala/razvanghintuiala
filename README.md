## What I've built

### Internal automation suite
`C#` · `.NET` · `Avalonia` · 2025 – present

A cross-platform desktop application that replaced a set of manual administrative processes with one tool:

- **Document processing** — OCR over scanned PDFs of variable quality, then automatic splitting and classification of every document by recipient name.
- **Official filings** — a dynamic XML generator validated against the regional government's published schemas, fed from data captured in Excel templates.
- **Email** — Outlook and Word integration through process hooks: personalized bodies and attachments built from Word templates that users edit themselves, without touching code.
- **Web portals** — an embedded browser (WebView2) with JavaScript injection handling authentication, navigation and data extraction on external sites.
- **RPA** — UI Automation and control hooks driving third-party desktop applications, including logins and repetitive flows, with no user input.
- **Generative AI** — the Claude API wired into the application's own workflows.
